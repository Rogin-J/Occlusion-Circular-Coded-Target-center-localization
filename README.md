# Occlusion-Circular-Coded-Target-center-localization
This is the code of paper "Comparative analysis on displacement measurement of CCTs with general occlusions in both the central region and coding band". Just run the Runme.m file in each folder.

Abstract: Circular Coded Targets (CCTs) are widely used in computer vision-based displacement measurement with their accuracy strongly depending on the robustness of extraction of their center point. The traditional single-contour method is computationally expensive, and it mainly relies on the central circle which is vulnerable to occlusion. A Multi-Peak Radial Aggregation Function (MPRAF) method is proposed in this study to address these issues. It integrates both the central circle and inner coding band contours within a histogram-based peak aggregation framework and the YOLOv8. This strategy avoids iterative data fitting, thereby achieving a large improvement in computational efficiency as well as an enhancement in accuracy. The detection performance of the proposed algorithm is systematically investigated with different occlusion scenarios. The validation with simulated static images, dynamic studies, and laboratory experiments shows that the MPRAF has an error in the estimated displacement which is smaller by more than 75% in many typical cases of occlusion compared with an existing method. The displacement resolution of the MPRAF is also noted as better than that of an existing method by one-third. Further studies reveal that the central occlusion has little influence on the YOLOv8 detection, whereas band occlusion can substantially impair the recognition. The proposed framework provides a practical solution for occlusion problems that may be encountered in long-term outdoor vision-based displacement measurement, enabling more reliable and robust displacement estimation under partial occlusion conditions.
Keywords: Circular Coded Target (CCT); Multi-Peak Radial Aggregation Function (MPRAF); Occlusion analysis; Center point localization; YOLOv8
